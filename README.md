# 항공권 가격 알림 (안드로이드)

출발지 · 도착지 · 가는 날 · 오는 날을 등록해 두면 핸드폰이 **1시간마다 스카이스캐너(skyscanner.co.kr)** 에서 최저가를 확인해 쌓고,
**바로 앞 확인 가격보다 10% 이상(설정 가능) 떨어지면** 핸드폰 알림을 띄웁니다. 알림을 누르면 그 검색 화면이 열립니다.

## 설치

1. 핸드폰에서 GitHub 에 로그인한 뒤 (비공개 저장소라서)
   https://github.com/gnb21c-cmd/air_search/releases/download/latest/air-search.apk 를 내려받습니다.
   (체험용 브랜치 빌드는 `test-build`: https://github.com/gnb21c-cmd/air_search/releases/download/test-build/air-search.apk)
2. 내려받은 파일을 열어 설치합니다. '출처를 알 수 없는 앱' 허용을 물으면 허용합니다.
3. 앱을 열고 **알림 허용**, 화면 위 **배터리 제한 풀기**를 누릅니다 (안 풀면 1시간마다 확인이 늦어질 수 있음).
4. 새 버전은 같은 주소의 파일을 다시 설치하면 덮어 설치됩니다 (등록 · 기록 그대로).

## 쓰는 법

- **+** → 출발지 · 도착지 코드(영문 3~4자: `ICN`, `GMP`, `NRT`, `KIX`, 도시 전체는 `SELA` 서울 · `TYOA` 도쿄 · `OSAA` 오사카), 가는 날 · 오는 날(편도면 체크), 인원.
- 등록하면 바로 한 번 확인하고, 그 뒤 1시간마다 확인합니다. 카드에 최근 가격 · 최저가 · 1주일 꺾은선, 누르면 최근 24번 기록.
- 가는 날이 지나면 자동으로 멈춥니다. 스위치로 잠시 끌 수도 있습니다.

## 어떻게 읽나

- API 키 없이, 화면에 안 보이는 웹 브라우저(WebView)로 사람이 보는 것과 같은 검색 화면을 엽니다.
- 페이지가 받아 오는 검색 결과(JSON)에서 항공편 가격을 엿보아 가장 싼 값을 씁니다 (`app/src/main/assets/hook.js`). 안 되면 화면의 '최저가' 칸 글자를 읽습니다.
- 스카이스캐너가 '사람 확인(로봇 아님)'을 요구하면 알림이 옵니다 → 카드의 **스카이스캐너 열기**에서 한 번 풀면 다시 됩니다.
- 비공식 방법이라 스카이스캐너가 화면을 바꾸면 읽기가 멈출 수 있습니다. 카드에 빨간 글씨로 이유가 나옵니다.

## 점검 (가격이 안 읽힐 때)

카드의 **점검** → 검색 화면이 눈에 보이게 열리고, 페이지가 주고받는 자료(주소 · 키 · 가격 칸)를 모두 적습니다 (`app/src/main/assets/diag.js`).
- 화면 아래 요약: 주고받은 자료 수 · 항공편(itineraries) 자료 수 · 앱이 엿본 최저가
- **숨은 확인 시험**: 1시간마다 하는 것과 똑같이 보이지 않는 창으로 한 번 확인 (최대 100초)
- **기록 보내기**: 점검 기록을 복사 · 공유 → 개발 대화창에 붙여 넣으면 실제 구조에 맞춰 고침

## 판단 규칙

`core/src/main/kotlin/kr/flightalert/core/DropRule.kt` — 기준은 **바로 앞 확인 가격**. 천천히 내려가는 것은 '갑자기'가 아니라 알리지 않습니다.
시험: `./gradlew -PcoreOnly :core:test` (안드로이드 SDK 없이도 됨)

## 만들기

GitHub Actions "Build APK" 가 push 마다 만들어 Release 에 올립니다 (main → `latest`, 그 밖 → `test-build`).
직접: `./gradlew :app:assembleRelease` (안드로이드 SDK 필요). 서명 키 `app/flightalert.keystore` 는 덮어 설치를 위해 고정 (개인용).
